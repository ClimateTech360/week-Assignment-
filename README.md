This program demonstrates polymorphism in Python using different vehicles.
Each class (Car, Plane, Bicycle, Boat) implements the same `move()` method, but each one behaves differently.
The `move()` method is called on each vehicle object, and it outputs the corresponding action (e.g., "Driving" for Car, "Flying" for Plane, etc.).

Classes:
- Car: Implements the move method that outputs "Driving 🚗"
- Plane: Implements the move method that outputs "Flying ✈️"
- Bicycle: Implements the move method that outputs "Riding 🚲"
- Boat: Implements the move method that outputs "Sailing ⛵"

Execution:
- A list of different vehicle objects is created, and their `move()` methods are called to display the respective actions.
